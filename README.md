# 🪑 Lume Sustainable Furniture - E-commerce Front-End

Este repositório contém a interface responsiva de um e-commerce de móveis chamado **Lume Sustainable Furniture**, desenvolvido como projeto prático de desenvolvimento Front-End com foco em layout moderno e adaptação para dispositivos móveis.

---

## 📱 Páginas Desenvolvidas

* **Home / Landing Page (`index.html`):**
  - Hero Banner com card de destaque responsivo.
  - Seção de categorias em grid simples e direta.
  - Vitrine de produtos organizados em grid adaptável para mobile e desktop.

* **Página de Categorias / Shop (`pages/products.html`):**
  - Barra lateral com filtros de preço, categoria e marca usando componentes nativos.
  - Grid de produtos com o botão de adição ao carrinho em destaque.

* **Página de Detalhes do Produto (`pages/product-detail.html`):**
  - Navegação por Breadcrumb (`Home / Products / Asgaard Sofa`).
  - Galeria de imagens com miniaturas alinhadas e destaque principal proporcional.
  - Seleção de opções (tamanho e quantidade) e informações do produto.

* **Página de Contato (`pages/contact.html`):**
  - Estrutura em duas colunas organizando dados institucionais e formulário de mensagem estilizado.

---

## 🎨 Referência de Design e Mídia

* **Layout:** O projeto foi desenvolvido tendo como estudo de caso e inspiração o protótipo [Furniro - E-commerce UI Kit no Figma](https://www.figma.com/files/team/1620948736756447228/resources/community/file/1331381641303792117?q_id=bf129e45-8aec-4325-b447-fc10325460c8&fuid=1620948733266063085). O design original serviu como base estrutural, com adaptações e personalizações próprias para simplificar a navegação e ajustar a composição visual da marca Lume além de atender os requisitos da entrega.
* **Imagens:** As fotografias dos 4 produtos que se repetem no projeto foram selecionadas da plataforma **Unsplash**, garantindo alta qualidade visual e licença livre para uso.

---

## 🛠️ Tecnologias e Recursos Utilizados

* **HTML5 / CSS3:** Estruturação semântica da página e estilização customizada.
* **Bootstrap 5:** Framework utilitário utilizado para o sistema de grid responsivo (`row`, `col-*`), espaçamentos e estilização de formulários e botões.
* **Bootstrap Icons:** Biblioteca de ícones vetoriais integrada para ações e informações visuais.
* **Google Fonts (Poppins):** Tipografia padrão aplicada em todo o projeto para manter a padronização e boa leitura.
